Raw artifacts: results/diagnostics/hanhai22-shared-response-20261012/.

Question and mathematics
------------------------
QOCGUM's saved trace is predominantly structure-residual limited. The old
mixed extension nevertheless invokes an orbital HVP at every admission.
The experiment preserves mixed extensions when the orbital residual dominates.
When the full coordinate structure residual is larger, it first tries a pure
structure source. An admitted source still returns both the structure Hessian
image and its orbital coupling adjoint. A rank-dependent CI source does not
consume an action; the original mixed direction remains available.

Orthogonalizing a pure source against mixed retained vectors introduces an
orbital component. Do not evaluate that component again: transform the new
Hessian and metric images with precisely the same Gram-Schmidt coefficients,
using linearity and the retained exact images. The observer receives the raw
source and matching metric image, not the transformed direction paired with
raw block images. Independence is tested before operator evaluation.

The projected generalized AH problem and complete residual are unchanged.
This changes direction ordering, not the HVP or the variational space. It is
not a theorem of better nonlinear convergence. AH tolerances, root selection,
keyframes, micro budgets, clipping, chart/retraction and outer tolerances stay
unchanged. No full Hessian, integral copy or thread-local large array is added;
the additional source/image workspace is shared and linear in coordinate size.

Rejected predecessor
--------------------
Build 1250959 / array 1250961 forced every admitted vector to be pure-sector.
QOCGUM fell to 37 orbital HVPs, but FeCl2 rose from 254 to 677 and MnF2 from
189 to 298. This policy was removed, not retained as an optional backend.
It is not equivalent to the retained experimental mixed-space implementation.

Validation and measurements
---------------------------
Final build/unit job 1250993; native array 1250994, indices 1,3,4,9,11,12.
Seven executables passed (direct-CI at 1 and 32 threads gives eight invocations).
New tests use unequal sector sizes 1+3, 2+2 and 3+1, nonidentity metrics,
positive/indefinite curvature, a sector-mixing preconditioner and gradient
refresh. Exact images/full residuals and the final generalized AH root agree
with dense references; pure-CI evaluations do avoid orbital actions.

Hanhai22, AMD EPYC 9654, GCC 14.1, Release -O3 -DNDEBUG -g1 frame pointers;
32 bound OpenMP cores, single-thread BLAS, exact Libcint, Davidson, analytic
Hessian diagonal, gradient tolerance 1e-3 and energy tolerance 1e-7 Eh.
Input and basis hashes match the saved e9fd6c7f response-local-1250866 runs.
Those saved runs were NOT rerun. Nodes differ: do not interpret single-run
timing differences as matched-node speedups or attribute all gains to this
change. Time is application end-to-end wall; RSS is GNU time process peak MiB.
Unrelated dirty RI source/test files were not transferred or committed.

All six final runs converge, maximum endpoint difference 5.74e-9 Eh.
QOCGUM: orbital HVP 52 -> 32, total admissions 52 -> 60, steps 4 -> 4,
wall 13.029036 -> 10.811728 s. Structure actions increase 52 -> 59.
CERRAS: orbital HVP 51 -> 34, admissions 51 -> 54, steps 5 -> 4,
wall 19.974193 -> 16.754030 s. Structure actions increase 51 -> 53.
FeCl2: orbital HVP 254 -> 274, steps 12 -> 13, wall 6.700096 -> 7.388638 s.
241 and MnF2 retain 21 and 189 orbital HVPs: their lower observed times do
not establish a direction-policy speedup. LOFLEA saves one HVP but wall time
increases from 33.999130 to 34.604009 s.

Old structure-action counters included exact-zero initial structure inputs;
new counters increment only for evaluated nonzero sectors. Do not claim that
the initial zero-action accounting correction itself saves a costly HVP.
Report all action types, not only the reduced orbital count.

Decision
--------
Keep implementation only on the experiment branch. Master retains e9fd6c7f's
optimizer and adds this evidence only: FeCl2's regression prevents presenting
this as a general default improvement. There is no molecule-specific switch.
The evidence demonstrates avoided orbital work for structure-dominated cases,
but not a safe global direction-selection policy. Study why four pure-CI
substitutions change FeCl2's early trajectory before replacing the default.
The historical c2776c4 QOCGUM target is still 13 HVP / 6.329732 s, so even
this improved experiment has not recovered historical performance.
