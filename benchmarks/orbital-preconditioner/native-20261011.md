# Return to single-node OpenMP/SIMD

## Scope

MPI was removed at the user's request, without resetting repository history.
The baseline is the archived native executable from revision `a9eb732`.

Removed: MPI session/service, integral sharding options, dispatcher hooks,
MPI build/developer targets, distributed-only tensor construction and launch
scripts. Historical reports and raw measurements remain labelled as archived.

Retained independent native improvements:

- Two sparse active-integral symmetry-factor corrections, with regression tests.
- A 32 MiB total private packed-tensor budget; large single-thread results are
  moved rather than copied.
- Shared forward/backward CSR/SIMD contractions instead of separate backward
  scatter images per thread.
- Shared exact closed-shell Fock construction with explicit density symmetrization.
- Generated-row accepted/directional contractions using disjoint row ownership.

No RI formulas, optimizer settings, convergence thresholds or iteration limits
were changed. This is a scope rollback, not a new scaling optimization.

regressions. The 32-thread result is about 3.6% faster, but RSS is 28.33 MiB
higher than this baseline capture; no overall memory reduction is claimed.

Scoped phases may be nested and must not be summed. The 16-thread integral
timings do not improve over eight threads, while selected-direction wall grows
with thread count. These are leads for affinity/NUMA, team/barrier overhead,
work partitioning and memory-bandwidth investigation, not an identified cause.
The next work targets single-node multi-core efficiency, not MPI.

Large arrays are not universally replica-free: native compact-stream scatter
still has private pair images, while CSR uses disjoint row ownership. No claim
is made that every native path now has a global memory bound.
