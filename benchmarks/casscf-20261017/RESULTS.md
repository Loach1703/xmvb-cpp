# Orthogonal CASSCF qualification, 17 October 2026

Parent revision: `65c1320b`. All builds and molecular evaluations ran in
Hanhai25 Slurm allocations, with 32 physical cores, core binding and serial
BLAS. The tested source and executable hashes, CPU model, affinity, raw
trajectories and GNU time reports are retained in each job artifact.
The completed-result table is generated by `collect.py`, not transcribed
from molecular output by hand. `results.csv` is its machine-readable output.

## Native input

Only the method flag was changed from `VBSCF` to `CASSCF` in the existing
F2 and FeCl2 input decks. Both converged and produced fixed-decimal `.orb`
files. F2: job 291885; FeCl2: job 291886. These runs include native libcint
loading and the existing AO screening convention. The CSV distinguishes
solver time from whole-process time (including input and integrals).

The first implementation is **exact, single-state, full CAS** and always
uses the shared CIAH solver. It does not implement state averaging or RI.
It neither generates VB structures nor uses a VB optimization objective.

## Same numerical initial frame

F2 job 291884 reads the same AO/MO fixture in C++ and PySCF coupled Newton.
The initial energies agree to about 3e-14 Eh. C++ reaches
-198.76111154174802 Eh in 4 macros / 16 HVPs, versus PySCF
-198.7611115415457 Eh in 3 macros / 24 coupled actions. Solver times are
0.1564 and 2.9946 s, with whole-process peaks of 58 and 92 MiB.
The difference in final energy is 2.02e-10 Eh.

PySCF's separate standard orbital-only AH calculation (job 291888) reads
that identical fixture and reaches -198.76111154007793 Eh in 4 macros,
5.7568 s of solver time, and 112 MiB peak RSS. Its callback is invoked for
both micro and macro updates: **12 callback records are not 12 macros**.
No AH HVP count is reported because that kernel does not expose `tot_hop`
through this callback. Coupled and orbital-only actions are not equated.

FeCl2 same-fixture PySCF coupled Newton (291883) and standard AH (291887)
were still running at this report snapshot. Their final energy agreement
and speed comparison remain pending. The native C++ result alone is not
a completed same-fixture comparison. Its 25 macros / 355 HVPs also leave
clear optimizer-performance work; no claim of uniformly improved macro
convergence is made.

The main F2 fixture uses a sigma-bonding/sigma-antibonding CAS(2,2) at
1.4 Angstrom, cc-pVDZ Cartesian, rather than the older VB F2 test's active
space. Older F2 energies must not be used as this fixture's baseline.
