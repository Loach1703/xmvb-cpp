# Minimum mixed-source contraction and framework audit

## Scope and implementation

The orthogonal-CI H/M restriction remains exact on arbitrary selected VB spaces.
This change minimizes its coordinate-anchored source factor count: original
input products form a bipartite support graph, maximum matching gives a minimum
row/column cover, and every edge is assigned to exactly one source. No amplitude
threshold, SVD truncation, enlarged tile budget, or physical-space admission is
introduced. A certified parity quotient changes only input representatives;
the complete original output support remains intact.

Causal exterior-adjoint plans are now accepted-point metadata rather than
rebuilt on every action. Structure incidences store the original-support group
index in the existing integer field, eliminating repeated binary searches in
source, product-tile and overlap back-projection without increasing incidence
storage. If the old beta-column cover is already minimal, its source ordering
is retained.

The layered augmenting-path planner uses heap-backed paths, not recursive
stack growth. Its temporary graph and persistent incidence plans are linear in
the touched support and one-spin dimensions, not the complete product grid.

## Remaining production bottlenecks found by source inspection

1. Accepted-state preparation still keeps dense raw/orthogonal/residual
   carriers per selected state. Directional and response consumers construct
   additional product arrays. Fixed-point H/M factorization has not migrated
   these consumers yet.
2. The selected-state coefficient producer already allocates a dense carrier;
   replacing only downstream operations will not fix its memory scaling.
3. Davidson diagonal construction without a supplied diagonal still traverses
   pairs of expansion terms. Its actual production contribution also depends
   on precomputed-diagonal producers and is not inferred from timing here.
4. Restricted metric completion enumerates full-product metadata and reserves
   carrier RHS workspace. This must be migrated along with gradients/HVP.

The ordered framework plan and ownership contracts are in the repository-root
`TODO_ORTHOGONAL_CI.md`. The next substantial numerical module is a shared
factor channel sweep with reverse/tangent consumers, not another larger cache.
No optimizer, convergence threshold or physical constraint changed this round.
