# Common solvers and data contracts

## Scope

First stage of the architecture refactor; parent `e28c6edb`. Move numerical
solvers to `mcscf/optimization` and `xmvb::mcscf`, without changing numerical
expressions or optimizer decisions. NEO/CIAH, MINRES, HVP basis operations,
spectral trust-region solves, algebraic preconditioners and scalar tracing
no longer belong to the VB model. Original solver headers and sources are
removed, not retained as forwarding interfaces.

`VectorAction` and `DualNorm` express caller-owned coordinates and metrics.
`mcscf/states/weights` replaces three duplicate weight normalizers. VB charts,
CI transport, physical curvature, preconditioner construction and macrostep
evaluation remain VB adapters. The unused `PfTwoElectronMode` contract is
removed. The common integral layer and full CASSCF orbital optimization are
not implemented by this change.

## Independent build and numerical tests

Hanhai22 build/test job **1264095**, anode42, passed **23/23** tests. Main
executable and both changed developer tools compiled successfully. Common
solver tests link only `xmvb_mcscf`; CASCI links `xmvb_casscf` and the common
library. Saved `nm -C` results contain zero VB function definitions for
`test_ciah`, `test_neo`, `test_minres` and `test_casci`. The VB-specific CI
phase/frame alignment regression moved to `test_keyframe` rather than being
discarded or forcing the common test to link VBSCF.

Tests include CIAH, NEO, MINRES, globalization, basis construction, algebraic
preconditioners, weights, CASCI, CI factors, structure/transport/metric
regressions, Davidson, eigen response, and F2 HAO/OEO Hessian-diagonal
optimizer checks. Earlier migration builds exposed namespace/call-site
omissions; those were corrected before the final successful job.

Compiler/dependency cache, source/binary hashes, raw test logs and linkage
symbols are retained in `evidence.tar.gz`. Local/remote source comparison
matched 493 files; the two differences are pre-existing local RI changes
deliberately excluded from this refactor and cluster transfer. Eight obsolete
test files still present in the execution mirror are not build inputs; their
new common paths are the compiled targets. Neither those mirror leftovers
nor local RI edits are compatibility paths in the repository.

## End-to-end COV regression

Original LOFLEA CAS(12,12) HAO guess, 132 structures, exact libcint cc-pVDZ,
CIAH/NEO, structure Davidson, analytic Hessian diagonal. Gradient tolerance
1e-3, energy-change tolerance 1e-7 Eh; no criterion or algorithm changed.
Eight pinned OpenMP cores in one LLC, BLAS one thread. Full convergence,
not a one-step timing. Saved baseline was not run again.
