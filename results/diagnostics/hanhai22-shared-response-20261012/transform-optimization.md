# Exterior transforms and accepted-point reuse

## Changes

1. Exterior forward, transpose, inverse and inverse-transpose actions now use
   two shared in-place kernels. Left actions own independent columns; right
   actions own independent row ranges with contiguous SIMD-friendly column
   segments. Shear order, source/target orientation and diagonal placement are
   preserved. There is no full-carrier worker copy and no barrier per shear.
2. Davidson returns its actual converged H image as well as its overlap image.
   The accepted-point context selects and retains these structure-space columns.
   The coupled model does not repeat the same H/S action. The finite CI residual
   is retained; H images are not approximated as energy times overlap images.
3. Chart geometry and curvature attachment are separate. NEO constructs the
   geometry once per accepted point and attaches curvature only before a step
   is needed. Converged endpoints no longer build an unused diagonal or AH
   mapping. Gauge complements and tangent bases are not rebuilt.

No HVP formula, optimization strategy, accuracy threshold or outer stopping
condition was changed. Existing unrelated RI edits were not included or synced.

## Validation

All builds and workloads ran in Hanhai22 Slurm, GCC 14.1.0, 32 OpenMP workers,
core binding, BLAS one thread, exact libcint integrals, Davidson, analytic
Hessian-diagonal NEO. Original inputs and tolerances are unchanged. The
comparison script verifies input SHA-256 against the saved baseline.

- Build 1250690: transform-only; explicit compound-matrix, inverse/adjoint,
  non-owning strided-block checks at 1 and 32 threads passed, as did five other
  keyframe, CIAH, coupled-structure, quotient and diagonal tests.
- Build 1250724: transform plus reuse. Eight test launches passed: exterior
  tests at 1/32 threads, Davidson, keyframe, CIAH, coupled structure, quotient,
  Hessian diagonal. Added checks cover returned H images, deferred analytic
  and one-electron preconditioning, and unchanged chart maps (including
  constrained/frozen supports and complete OEO).
- Native transform-only arrays 1250698 and 1250709; final array 1250728.
- Diagnostic two-macro jobs 1250729 (LOFLEA) and 1250730 (FeCl2). Application
  exit 2 is expected at this diagnostic iteration limit; full native tests
  converged independently. Diagnostic timings are not production benchmarks.

All five converged. Final energies and exact values are in
`transform-comparison.csv`, regenerated by `compare-transforms.py`.
No blanket speedup or lower-RSS claim is justified: the substantial measured
gain is CERRAS (1.86x) and LOFLEA (2.12x). FeCl2 is slower in this sample and
must be reported as such. There is no thread-count-proportional carrier storage.

Transform-only native times were 18.878 s for CERRAS and 39.546 s for LOFLEA,
with the same steps/HVP counts as before. Thus most of the demonstrated gain
was present before the duplicate-operation cleanup. Different nodes prevent
assigning the remaining difference exclusively to the cleanup.

## Phase evidence

LOFLEA two-macro traces, same 13 coupled HVP expansions:

| Scope | Previous trace 1250665 / s | New trace 1250729 / s |
|---|---:|---:|
| Trial forward, including three CI solves | 35.314 | 8.900 |
| Orbital HVP apply | 4.566 | 3.062 |
| All sigma calls (nested across consumers) | 12.079 | 8.923 |
| Left exterior transforms | not separately measured | 0.478 |
| Right exterior transforms | not separately measured | 1.222 |

These rows overlap and must not be summed. Sigma calls decrease from 368 to
366, consistent with reusing the selected images at the two points whose
coupled model is used. The final truncated point has no subsequent model.
Analytic diagonal builds decrease from three to two. No physical contribution
was discarded.

FeCl2's two-macro diagnostic spends 0.0125 s in left transforms and 0.0073 s
in right transforms. These numbers do not support blaming the transform
kernel for the full-run timing regression. Do not add a molecule-specific
parallel switch or change convergence thresholds on that basis.

## Limits and next work

This change optimizes nondirectional exterior actions. Directional jet methods
remain separate and unchanged; their residual cost should be measured before
another rewrite. Small systems still have other dominant costs. No MPI,
new global carrier cache, full H/S matrix, or thread-private large array was
introduced. VTune remains unavailable under the current ptrace policy; the
evidence here is native comparison and explicit phase scopes, not a valid
sampling profile.
