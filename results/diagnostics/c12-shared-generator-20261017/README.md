# Shared-right generator qualification

The change adds independent multi-left moments on shared generated right
columns. The single-left interface delegates the same engine. The product jet
uses it for the orbital and CI Hamiltonian images, then for both accepted
residual tail moments; output Hamiltonian blocks are borrowed rather than
copied. See `article/shared_generator_adjoint.md` for the exact bilinear formulas.

Hanhai22 job1264759 used the unchanged C12/LOFLEA exact-integral HAO CIAH input,
anode40,32 physical cores and the same C++23/Release/BLAS1 toolchain and affinity
as saved job1264713. The existing regression launcher records all hashes and
flags. Old binaries were not rerun. The9 regressions passed, including new
independent dense-oracle multi-left tests with unequal spins, transient and
retained columns, exchange parity+/-1, symmetric moments and exact-zero lefts.
Existing full physical coupling tests also passed.

The native gain is only0.5% and is not a robust end-to-end speedup claim.
In separate phase-instrumented runs, generator-adjoint calls fall704→416 and
their scoped wall0.353564→0.323959s. Complete coupled-image wall instead
changes9.768215→10.003442s and application wall28.592445→29.068800s. These
scopes overlap. The change removes real repeated reads/topology walks but this
was not the dominant stage. It is retained as the single common contraction
engine, not as a claimed large performance breakthrough. Workspace growth is
only an additional small orbital matrix per worker per borrowed left panel;
there is no carrier replication or relaxed threshold.

The larger remaining transport cost is independently visible:
`ci_exterior_generator_pullback`440calls/2.317848s, inside the11 finite
transport-gradient calls taking2.685966s. This motivates examining that path
next rather than extrapolating the small streamed-kernel gain.
